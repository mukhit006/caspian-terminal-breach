# BREACH — Caspian Terminal

Браузерный тактический 3D-шутер. Выбери операцию, снаряжение и отправляйся на полигон.

## Играть

После включения GitHub Pages игра будет доступна по адресу:

https://mukhit006.github.io/caspian-terminal-breach/

Нужен современный браузер с WebGL и доступом в интернет: Three.js и веб-шрифты загружаются с CDN.

## Управление

- `W A S D` — движение, мышь — обзор
- `Space` — прыжок
- `ЛКМ` — выстрел или удар ножом
- `ПКМ` / `Q` — прицеливание
- `1–3` — основное оружие, `4` — нож
- `R` — перезарядка, `E` — действие
- `B` — арсенал, `Esc` — освободить курсор / закрыть меню

Сохранение коллекции и кредитов хранится в браузере на этом устройстве.
